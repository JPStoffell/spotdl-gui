SpotDL - Spotify Downloader GUI
Version 1.0.0

A beautiful desktop application for downloading Spotify playlists.

Features:
- Download Spotify playlists, albums, and individual songs
- Automatic metadata and album art
- Customize output folder and filename format
- Real-time download progress
- Save download history

Requirements:
- Windows 10 or later
- Internet connection
- ~500 MB free space

First Run:
- The app will download FFmpeg automatically on first use
- Music will be saved to: Music/SpotDL Downloads/

Settings:
- Change output folder in app
- Customize filename format
- Skip existing files option

Support:
- GitHub: https://github.com/spotdl/spotify-downloader
